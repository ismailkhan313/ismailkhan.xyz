* **Note**: The captured docs are version **2026-07-28**, which differs from widely circulated accounts of MCP in ways the page flags explicitly: the protocol is now stateless (every request carries its version and capabilities in `_meta`, with `server/discover` replacing the `initialize` handshake), and the **sampling** and **logging** client primitives are **deprecated** — elicitation is the only client primitive left. Worth re-checking against the spec before relying on any older MCP summary.
